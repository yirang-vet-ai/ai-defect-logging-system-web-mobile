# Code of Conduct

This project expects respectful and constructive participation.

## Expected behavior

- Be respectful in communication
- Focus feedback on code, design, and reproducible issues
- Share improvements in a professional manner
- Credit prior work appropriately

## Unacceptable behavior

- Harassment or personal attacks
- Discriminatory or abusive language
- Deliberate misrepresentation of work
- Malicious code or unsafe repository modifications

Project maintainers may remove content or contributions that violate these expectations.
