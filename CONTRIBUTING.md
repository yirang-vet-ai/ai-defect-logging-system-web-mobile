# Contributing

Thank you for your interest in contributing.

## How to contribute

1. Fork the repository
2. Create a feature branch
3. Make focused changes
4. Test your update locally
5. Open a pull request with a clear summary

## Guidelines

- Keep code readable and modular
- Preserve the existing folder structure where possible
- Document any new dependency
- Clearly mark modified files
- Avoid committing trained model binaries unless necessary

## Reporting issues

Please include:

- operating system
- Python version
- TensorFlow version
- full error message
- reproduction steps
