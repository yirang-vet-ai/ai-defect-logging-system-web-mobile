# Usage Guide

## 1. Prepare dataset
Create `train/` and `validation/` folders with class subfolders.

## 2. Train
Run:

```bash
python train_neu_from_train_validation.py
```

## 3. Predict a single image
Run:

```bash
python predict_one_neu.py sample.jpg
```

## 4. Launch Streamlit
Run:

```bash
streamlit run app.py
```

## 5. Open in browser
- Desktop: Local URL
- Mobile: Network URL on the same Wi-Fi
